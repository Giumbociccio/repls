# Struttura base del Markdown
✨ Titoli
Si usano i # come in questo esempio:

markdown
Copia
Modifica
# Titolo principale (H1)
## Sezione (H2)
### Sottosezione (H3)
#### Dettaglio (H4)
❗ GitHub consiglia un solo # (H1) per il titolo principale del README.md.

✒️ Testo
Grassetto: ** testo ** → **testo**  


Corsivo: * testo * o _ testo _ → _testo_


Barrato: ~~ testo ~~ → ~~testo~~


Codice inline: `codice` → codice


Citazioni:
>
> Questo è un blocco citazione


📋 Liste
Liste puntate:
- Punto 1
- Punto 2
  - Sottopunto
Liste numerate:
1. Primo
2. Secondo
   1. Sottoelemento

🧱 Blocchi di codice
Inline:
` codice ` → `codice`

Blocchi multilinea: tre `
```linguaggio
codice qui
```

Esempio:

<pre> ```python def somma(a, b): return a + b ``` </pre>
Puoi usare linguaggi specifici (python, java, bash, json, html, ecc.) per evidenziare la sintassi.
